**Project Portal Anime** adalah aplikasi *high-performance web wrapper* yang dirancang khusus untuk memberikan pengalaman menonton anime yang mulus, bersih, dan cepat di perangkat Android. Menggunakan teknologi **AppMint Premium**, aplikasi ini mengubah portal web menjadi aplikasi native dengan optimasi maksimal untuk penggunaan mobile.
---
## 🚀 Fitur Utama
Aplikasi ini dikembangkan dengan fokus pada kenyamanan pengguna dan efisiensi performa di smartphone:
* **🛡️ Standard AdBlock System:** Menghilangkan iklan yang mengganggu secara otomatis agar fokus menonton tidak terganggu.
* **🔐 Integrated Login System:** Mendukung sinkronisasi akun pengguna untuk menyimpan daftar tontonan (watchlist) dan riwayat secara aman.
* **⚡ AppMint Premium Engine:** Dibangun menggunakan wrapper premium untuk memastikan UI yang responsif dan waktu pemuatan (loading) yang instan.
* **🤖 AI-Assisted Development:** Kode dan arsitektur aplikasi dioptimalkan dengan bantuan kecerdasan buatan untuk memastikan minim bug dan performa stabil.
* **🎨 Cyber-Neon Interface:** Estetika antarmuka yang modern dengan perpaduan warna gelap dan aksen neon yang nyaman di mata untuk penggunaan jangka panjang.

## 📥 Instalasi & Penggunaan
1.  **Download:** Unduh file installer (.apk) dari folder [Releases](../../releases).
2.  **Install:** Buka file APK di perangkat Android kamu. Pastikan kamu telah mengizinkan instalasi dari "Sumber Tidak Dikenal" di pengaturan keamanan.
3.  **Login:** Gunakan akun Portal Anime kamu untuk masuk dan menikmati fitur premium.
4.  **Enjoy:** Mulai jelajahi ribuan judul anime tanpa gangguan iklan langsung dari genggamanmu!
---
## 🛡️ Keamanan & Privasi
Aplikasi ini sangat menghargai privasi pengguna. 
- Sistem **AdBlock** kami hanya bekerja pada level elemen iklan dan tidak membaca data pribadi.
- Data login disimpan secara terenkripsi melalui sistem keamanan **Hash265**.
